# Cozy Nature GLBs

## Goal
Use suitable Grab3D Cozy Nature models for existing 3D trees and directly matching nature props, preserving map placement, seasons, felling and bounded forest rendering.

## Files to change
- `godot/assets/nature/`: only selected GLBs, import/textures, source manifests/notices, provenance and full CC0 text; `SOURCES.md` records selection and transforms.
- `godot/buildings_3d.gd`: cached source meshes/materials and existing instanced tree routing; retain simple far LOD and existing bollards.
- `godot/map_chunk.gd`: prepare shared resources before workers; pass only necessary season/leafless data through tree/forest rows; retain rebuild/lifecycle behavior.
- `godot/i18n.gd`, `godot/startup.gd`, `tools/license_inventory.json`: selected sources in displayed fi/en/de credits and licence coverage.
- `godot/tests/cozy_nature.gd`, `godot/tests/manifest.txt`, relevant existing tree/forest checks: meaningful geometry/state/LOD regressions.
- `godot/visual_test.gd`, `tools/visual_scenarios.json`: bounded readiness for selected sources in named real-map views; change only relevant hunks.
- Local `docs/visual-quality-corrections.md` and evidence: exact suitability decisions, measurements and commands; keep audit/spec/evidence local per user instructions.

## Behaviour / acceptance criteria
1. Inspect actual [Cozy Nature](https://grab3d.com/kits/cozy-nature/) downloads before selection. Prioritize [Spruce Tree](https://grab3d.com/models/nature/spruce-tree/), [Pine Tree](https://grab3d.com/models/nature/pine-tree/) and [Birch Tree](https://grab3d.com/models/nature/birch-tree/) for their matching existing species; no tropical/ornamental species substitution. Measure transforms, dimensions, triangles, materials, texture size and separable trunk/foliage parts; choose offered lighter variants when visually adequate.
2. Normal shaded 3D mapped trees use selected compatible GLB species, with stable position-seeded yaw/variation. Forest near batches may use the same meshes only within a bounded range justified by the density comparison below; keep existing simple distant crowns and population/road-clearance rules. If dense GLBs exceed the budget, retain procedural forest batches and document the exact boundary; mapped trees still use the kit.
3. Keep source geometry, UVs, normals, tangents, textures and authored child transforms through batching. Whole trees use uniform scale, ground-centred at their original position; match existing radius/height envelopes without enlarged road intrusion. Record any authored submesh selection (e.g. remove decorative ground pads) explicitly; never discard branches or replace the source with primitives.
4. Preserve seasonal color/variation, conifer snow and bare winter birch. Tint only appropriate foliage/snow surfaces and keep bark/material details. Use existing season weights and leafless state; a source lacking separable foliage may keep the existing bare-birch fallback rather than display summer leaves in winter. Record and test every retained seasonal fallback.
5. Preserve server-owned fallen angle and reset/reload behavior. Prefer laying the selected whole tree when it fits the corrected fallen envelope; evaluate [Fallen Log](https://grab3d.com/models/nature/fallen-log/) only as a trunk replacement with the existing crown if source fit keeps full length, visible trunk/crown contact and grounding. Reject incompatible log geometry with a concrete reason, keeping the corrected fallback and shipping no unused log.
6. Evaluate [Bush](https://grab3d.com/models/nature/bush/) only for existing `shrub` rows and [Boulder Rock Set](https://grab3d.com/models/nature/boulder-rock-set/) only for existing `boulder` rows. Use them if a uniformly fitted authored bush/single rock matches the current envelope; select separate authored rocks rather than turning a mapped single boulder into a group. Retain an unsuitable kind and explain why. Add no new plants, decorative populations or map data.
7. Reuse immutable caches and MultiMesh/per-material batches, prepare GLBs on the main thread before workers, and keep per-frame work bounded. No per-tree scene nodes/material clones or resource creation on workers. Rebuild/replace/unload/reload and near/far transitions preserve counts, material isolation, layers and shadow policy; bollards, 2D paths and unrelated GLBs remain correct.
8. Store exact model/download URLs, date, original source notices/manifests, unchanged download hashes, measured counts/bounds and runtime transforms. Record CC0 1.0 legal text and selected model attribution in docs and visible Finnish/English/German credits; inventory only shipped files.
9. Pass and inspect named daylight views proving actual mapped selected tree/shrub/rock geometry, plus snow/leafless and felled views for changed branches. Reuse sourced tree-row/Bulevardi and `walk_boulder_day`/forest scenarios where applicable. Readiness identifies source meshes/materials and actual rows, grounding, active camera/layer, useful projected coverage and unobscured features; normal map/time/weather/chunk checks must pass. Never inject new nature placements to satisfy a capture.
10. Compare native GPU dense-forest and mapped-tree views against the prior revision using identical scenario, resolution, settings, tree populations and measurement interval. Record p50/p95/p99, draw/triangle counts and chunk build timings; investigate >10% p95 regression or extra streaming stalls before choosing the shipped near/forest scope. WSL software rendering cannot establish GPU performance.
11. Run focused source/transform/state/lifecycle checks, existing tree/forest/felling controls and relevant licence/manifest checks. Inspect source multi-angle and passing real-game screenshots. Report every selected/retained candidate and performance limitation; preserve unrelated shared edits and local audit files.

## Tests to add
- `godot/tests/cozy_nature.gd::test_selected_source_geometry`: production batches contain measured selected source triangles/material attributes; primitive substitutions, missing branches or wrong rock groups fail.
- `godot/tests/cozy_nature.gd::test_fit_seasons_and_felling`: representative species/radii/yaws, translated/nonzero DEM positions, summer/winter/leafless states and multiple fall angles preserve fit, grounded contact and fall/reset state; distortion, floating roots, summer winter foliage or disconnected crown fails.
- `godot/tests/cozy_nature.gd::test_batch_lifecycle_and_lod`: mixed repeated trees/props, rebuild/unload/reload, near/far transitions, stable counts/resources and bollard/2D controls; cache races, per-instance material mutation or doubled trees fail.
- `godot/tests/cozy_nature.gd::test_provenance_and_credits`: selected downloads match hashes/manifests, CC0/inventory and displayed fi/en/de credits; missing attribution or unused shipped assets fail.

## Out of scope
New scenery populations, plant/flower gameplay, hedge-line redesign, species inference, server collision/felling decisions, traffic/road-maintenance changes, new cameras, whole renderer refactors, and historical audit rewrites. Commit verified implementation in logical pieces after independent tester PASS; push through /ship finalizer.
