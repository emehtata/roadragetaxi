# Pitched tent and entrance (VQA-026)

The tent now has a pitched roof and a visible forward entrance. The accepted named screenshot and all 32 comparison panels were inspected; excluded attempts receive no visual credit.

The production path is `osm/campsites.py::populate_camp_pitches()` → streamed `scenery_objects` → `map_chunk.prepare()` / `_structures()` ground props → `Buildings3D.props()` → final ground mesh. The old tent used the generic `_raised_polygon_at()` fallback and therefore became one **2.4×2.0×1.3 m** flat-roof box. The Python `CAMPING_SIZES` envelope is **3.2×2.4 m**. The existing 2D branch already has two fabric faces, a longitudinal ridge and a dark entrance at +X.

The tent-only 3D branch now emits two sloping fabric panels and triangular ends. Its ridge follows local X at y=1.3 m, base remains x±1.2/z±1.0 m at ground height 0. The green fabric keeps `PROPS.tent`'s existing palette. A dark `Color8(28,49,51)` triangular entrance on the forward +X end spans y0.03–0.95 and z±0.55 m. The front fabric sits 2 mm behind the doorway, avoiding coplanar flicker while remaining within 5 mm contact tolerance. All 21 vertices lie within the original dimensions and server camping envelope. Existing winding helpers, static chunk material/shadow path and terrain adaptation are reused.
